# 0030 – One name everywhere

- Status: accepted
- Date: 2026-11-13
- Extends: 0004

The project is called `nestegg` everywhere: the GitHub repository, the local
checkout directory, the crate, the binary, the Debian package and the
documentation. Earlier working titles that described the project ("Linux PC
backup over Proxmox Backup Server") are no longer used as names.

Spelling: `nestegg` in lower case in commands, paths and package names, and
also in running text, as in the README. It is never shortened to "nesteg" and
never contains "Proxmox" (see 0004).

The planned move to a dedicated GitHub organisation (0004) is unchanged; the
repository keeps the name `nestegg` there.
